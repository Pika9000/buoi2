# Mộc Market

Trang giới thiệu siêu thị mini được làm bằng HTML và CSS đơn giản, dùng Vite để chạy trên máy.

## Chạy trang web

```bash
npm install
npm run dev
```

Mở địa chỉ hiện trong terminal, thường là `http://localhost:5173`.

## Tệp chính

- `index.html`: nội dung trang web.
- `style.css`: định dạng giao diện.
